# 词刻多语词书 Android 3.0.2

安装包：`dist/Cike-Multibook-3.0.2.apk`

## 系统要求

- Android 6.0 或更高版本
- 首次安装需要允许“安装未知应用”
- 学习数据、头像、笔记和私人图书只保存在本机

## 本版包含

- 修复“显示释义 → 没记住/模糊 → 下一个”交互卡住，答题后自动把“下一个”滚入可点击区域
- 修复写译长文本在窄屏被裁切，并限制 320、375、390、430 px 宽度下无页面横向溢出
- 增加系统语音准备中、语音包缺失和播放失败提示；朗读失败不再无反馈
- 更新离线缓存版本，覆盖安装后不会继续使用旧版脚本
- 上传资料会按 Markdown 标题、DOCX 标题样式、中英文章节标题自动拆分学习章节
- 阅读器提供逐句翻译编辑、本地逐句词义辅助、独立语句分析和每 30 秒阅读计时保存
- 手绘纸张与铅笔线框视觉、启动页、粒子与滑动进入按钮
- 五段圆角底部导航：今日、词库、图书、写译、我的
- 页面过渡、按钮按压反馈和 Web Audio 点击音效
- TypeWords 全部 194 本公开词书，共 273,630 条引用、31,976 个去重词条
- 六级核心 2000、附件 1526、英语万词、法语 A1–B2 5000
- 用户提供的 14 本私人阅读资料（重复 Kumo 文件已去重）
- PDF、DOCX、TXT、Markdown、EPUB 和图片导入
- 本地 OCR：英语、法语、简体中文
- 写译语言选择、文档选择、章节与板块闯关、字号调节、默写草稿
- 图书语言与类型筛选、文字/PDF 图像阅读、笔记、译文编辑、语句分析
- 个人头像、姓名、标签、本地阅读时长和阅读字数
- 智能复习：词书、翻译草稿、阅读收藏
- 基础 JSON 备份与包含本地图书文件的完整 ZIP 备份

## 内容说明

- 7 本图像型 PDF 随 APK 保存，因此安装包约 450 MB。
- 其余 PDF/EPUB 已提取为分页文字；原始用户文件仍可在完整备份中使用。
- 漫画、绘本和扫描 PDF 使用逐页图像阅读；可手动启动离线 OCR。
- 当前版本不会伪造自动翻译、语法评分或未授权的公开内容。

## 发音

英语和法语使用 Android 系统 TextToSpeech。如无声，可在应用“设置 → 系统语音设置”中安装或选择对应语音包。

## 安装

1. 发送 `Cike-Multibook-3.0.2.apk` 到 Android 手机。
2. 在文件管理器中点击 APK；若文件名末尾被添加 `.1`，先重命名删除 `.1`。
3. 小米 HyperOS 如拦截，搜索“安装未知应用”并允许文件管理器安装。
4. 安装后打开“词刻多语词书”。

## 数据来源

见 `NOTICE-MULTIBOOK.md`。用户上传或提供的私人书籍不随公开代码仓库分发。
