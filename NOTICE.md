# Data attribution

The application code is licensed under the MIT License.

The vocabulary data in `data/words.js` is a transformed and selected subset of:

- **exam-data/CETVocabulary**
- Source: https://github.com/exam-data/CETVocabulary
- Base data license: **CC BY-NC-SA 4.0**
- Method described by the source project: CET vocabulary from the 2016 revised syllabus, ordered by frequency across roughly 200 English exam papers.

This derivative keeps the source project's frequency and vocabulary facts, adds a 2,000-word selection, exam-use tags, units, and app-specific metadata. It is shared for non-commercial study use under the same CC BY-NC-SA 4.0 terms. Attribution must be preserved when redistributing the data.

Examples and translations are included only where present in the source dataset. No claim is made that the list is an official CET-6 examination word list.
