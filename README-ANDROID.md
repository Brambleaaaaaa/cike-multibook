# 词刻多语词书 Android 版

安装包：`dist/词刻多语词书-2.0.0.apk`

## 系统要求

- Android 6.0 或更高版本
- 首次安装需允许“安装未知应用”
- 软件完全离线，不需要账号、网络或浏览器

## 安装

1. 把 APK 发送到 Android 手机。
2. 在文件管理器中点击 APK。
3. 系统提示时，允许当前文件管理器或浏览器“安装未知应用”。
4. 安装完成后，从桌面打开“词刻多语词书”。

## 已包含内容

- 六级核心 2000 词
- 六级附件 1466 词 + 60 个语境词组
- 英语万词扩展 10000 条
- 法语 A1–B2 5000 词
- 六级写译 206 PDF 的 55 页背诵原文
- 看词回忆、听力默写、释义默写、错词回炉、学习统计、备份导入导出
- 每日学习次数不设上限；每组词数可以自由设置

## 发音

英语和法语使用 Android 系统 TextToSpeech：

- 如果某语言没有声音，请在手机的“设置 → 系统 → 语言与输入 → 文字转语音”中安装对应语言语音包。
- 即使没有语音包，看词回忆和释义默写仍可正常使用。

## 数据与导出

- 学习记录保存在应用自己的本地存储中。
- 导出备份会保存到手机的 `Download/词刻多语词书` 目录。
- 卸载应用会删除应用内进度，卸载前请先导出备份。
